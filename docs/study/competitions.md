# 竞赛名录

## 官方对竞赛的认定

抛开简历上的加分项不谈，学校认可的竞赛在保研推免中会有直接加分。哪些竞赛被认可、加多少分，每年可能会有调整，请以教务处当年发布的文件为准；文件之外，各院系也可能会扩展一些自己认可的竞赛名目，可到院系官网查询。

<LinkList :links="$frontmatter.links" />

## 如何报名参加

部分竞赛学校会统一组织报名，请关注所在院系的通知，也可以直接咨询辅导员或任课老师。数学建模类竞赛参与门槛相对友好，许多理工科同学的第一场比赛就是从这里开始的。
