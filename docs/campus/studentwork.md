# 学生工作

学生工作（简称「学工」）机会多、组织多，在决定要不要做学工之前，不妨先想清楚自己的目的，再决定做什么。以下仅从大的方面做简单梳理，不追求覆盖所有院系/社团的具体安排。

## 学生组织有哪些

学生组织大致可以分为四类，每类下又有不同级别或性质：

- **团委**：校级 / 院级 / 班级
- **学生会**：校级 / 院级
- **社团**：兴趣类 / 专业实践类
- **书院**：复旦特色的五大书院组织

社团数量众多，可通过下面的社团清单按 tag 检索：

每个团体下通常又分为若干组别，以复旦大学学生会为例：

- 组织建设部：人力、秘书处
- 联络发展部：内联、外联、权益
- 学术文化部：星空、旷宇
- 文体活动部：创意研究、活动实践
- 融媒体中心：新媒体中心、复旦人周报
- 枫林校区办公室：上述职能在枫林校区的对应设置

不同社团的具体架构差异很大（例如科技类社团通常不设文体活动部），团委的组织形式也与学生会/社团不太一样，可搜索「复旦团委招新」了解详情。

## 具体做什么

- **团委**：偏监督管理，负责团务、评奖评优、青马工程、团校等
- **学生会 / 书院**：偏活动执行，服务同学，每学期有对应的活动 KPI
- **社团**：围绕自身领域组织活动，自由度相对更高

每个团体内部大致有三层：

- **管理层**：主席团、部长、社长
- **执行层**：副部、干事
- **氛围组**：划水、挂名干事

组织规模越大（如校/院学生会），一般门槛和考核标准也越高，专业分工更细；但规模小不代表更容易进，部分热门社团的门槛同样不低。

## 怎样选择

做学工前先问自己：目的是什么？学工是不是达成这个目的最好的手段？如果不是，还有没有更直接的路径（例如为了学一项技能，自学是否比借助学生组织更高效）。

想清楚目的之后再决定是否加入：每学期各组织几乎都有招新，这学期没赶上，下学期还有机会；如果只是担心自己没有目标、不知道拿空余时间做什么，也不必勉强自己背上负担。选择是个人的，量力而行、自己想清楚即可。
